# RoadLab Manual — ตัวจำลองขับรถด้วยตัวเอง

เวอร์ชัน PC สำหรับทดลองก่อนเชื่อม STM32 ทุกการคำนวณในชุดนี้ทำบนคอมพิวเตอร์ ยังไม่มีการรับคำสั่งจากบอร์ดและไม่ใช้ firmware ชุดขับอัตโนมัติเดิม

## เปิดโปรแกรม

1. แตก ZIP ทั้งโฟลเดอร์
2. ดับเบิลคลิก `START_PC.cmd` แล้วเปิดหน้าต่าง server ค้างไว้
3. เปิด Chrome หรือ Edge ไปที่ `http://localhost:8767`
4. เลือก “ถนนว่าง” แล้วกด “เริ่มขับ”
5. ลองคันเร่ง 30–50% ก่อน จากนั้นฝึกเลี้ยวและเบรก

ต้องมี Python 3 ไม่ต้องติดตั้งแพ็กเกจเพิ่ม และรวม three.js ไว้แล้ว จึงเปิดใช้งานแบบไม่ต่ออินเทอร์เน็ตได้ หากเปิดด้วยไฟล์ HTML โดยตรงจะโหลด JavaScript module ไม่ได้

หาก script หา Python ไม่พบ ให้ติดตั้ง Python 3 หรือใช้ Python ที่มีอยู่รัน:

```powershell
py -3 server.py --open
```

ถ้า port 8767 ถูกใช้อยู่ ให้เปิด URL เดิมหากเป็น RoadLab Manual ที่เปิดค้างไว้ หรือรัน `py -3 server.py --port 8768` แล้วเปิด `http://localhost:8768` แทน กด Ctrl+C ในหน้าต่าง server เพื่อปิด

## ควบคุมรถ

| คำสั่ง | วิธีใช้ |
|---|---|
| คันเร่ง | แถบเลื่อน 0–100% หรือกด W / ลูกศรขึ้นค้างเพื่อเพิ่ม และ S / ลูกศรลงเพื่อลด |
| เลี้ยว | A / ลูกศรซ้าย และ D / ลูกศรขวา หรือกดปุ่มบนหน้าจอค้าง |
| เบรก | Space ค้าง หรือกดปุ่มเบรกบนหน้าจอค้าง |
| พัก | Esc หรือปุ่มพัก แล้วกดขับต่อเพื่อทำต่อ |
| เริ่มใหม่ | Reset คืนรถไปจุดเริ่มและตั้งคันเร่งศูนย์ |
| หยุดฉุกเฉิน | Emergency Stop หยุดฉากทันที ต้อง Reset ก่อนเริ่มใหม่ |

คันเร่งกำหนดกำลังขับ ไม่ใช่ความเร็วเป้าหมาย รถเร่งและลดความเร็วตามแบบจำลอง ความเร็วสูงสุดของแบบจำลอง 90 km/h

ขณะกดเบรกจะตัดคันเร่ง เมื่อปล่อยเบรกจะกลับใช้ค่าคันเร่งบนแถบ หากต้องการจอดค้าง ให้ลดคันเร่งเป็นศูนย์ด้วย

ปล่อยปุ่มเลี้ยวแล้วล้อค่อย ๆ คืนตรง แต่ตัวรถยังคงทิศที่หันอยู่ เมื่อต้องการให้รถกลับขนานถนน ให้เลี้ยวสวนเล็กน้อย ระบบไม่มีการรักษาเลนหรือปรับมุมให้โดยอัตโนมัติ เริ่มจากความไว “นุ่มนวล” และกดสั้น ๆ ก่อน

ขณะกำลังแก้ค่าช่องเลือกหรือแถบเลื่อนด้วยคีย์บอร์ด ปุ่มลูกศรจะควบคุมช่องนั้น ให้คลิกบริเวณฉากก่อนกลับมาขับ ปุ่มเบรกบนหน้าจอใช้ได้เช่นกัน

## ทดลองสถานการณ์

- ถนนว่าง: ฝึกบังคับรถ
- รถขวางกลางและขวา / กลางและซ้าย: ฝึกเบรกและตรวจพื้นที่หลบ
- รถขวางทุกเลน: ฝึกหยุดก่อนชน
- รถช้าด้านหน้า: TTC ใช้ความเร็วที่กำลังเข้าใกล้
- รถเร็วด้านหลังซ้าย: ตรวจว่าพื้นที่ซ้ายถูกกันไว้แม้ไม่มีรถขวางด้านหน้าซ้าย
- ปุ่ม + ซ้าย / + กลาง / + ขวา: เพิ่มรถในเลนที่เลือก ห่างตามแกนถนนจากจุดกึ่งกลางรถเรา 15, 35 หรือ 60 เมตร ระยะว่างที่แสดงบนจอหักความยาวรถแล้ว จึงน้อยกว่าตัวเลขที่เลือก

## คำเตือน

ระบบตรวจระยะ ความเร็วเข้าใกล้ และแนววิ่งตามทิศรถปัจจุบัน คำนวณระยะหยุดจากความเร็ว เวลาเผื่อตอบสนองที่เลือก ความหน่วงเบรก 8 m/s² และระยะสำรอง 3 เมตร

- เริ่มเสี่ยง: เตือนลดความเร็ว
- ประเมินว่ามีระยะหยุด: เตือนเบรก
- ระยะหยุดไม่พอ: เตือนเบรกเต็มที่ และแนะนำซ้ายหรือขวาเฉพาะเมื่อผ่านเงื่อนไขพื้นที่และเวลาการเลี้ยวโดยประมาณ
- ไม่มีพื้นที่หรือเวลาไม่พอ: ไม่แนะนำทิศทางหลบ

การคำนวณพื้นที่เลนข้างใช้การคาดการณ์รถรอบข้าง 3 วินาที รวมรถด้านหลัง การเปลี่ยนความไวพวงมาลัยมีผลกับเวลาหลบที่ระบบประเมิน เลนสีเขียวจึงไม่ได้หมายความว่าจะเลี้ยวทันทุกครั้ง คำแนะนำอาจเปลี่ยนตามการเคลื่อนที่

ระบบประเมินนี้ยังเป็นกฎประมาณสำหรับการเรียนรู้ ไม่มีการรับประกันว่าหลบได้ทุกฉาก และไม่แทรกคำสั่งเลี้ยวหรือเบรกเอง ผู้ใช้ต้องควบคุมรถเองตลอด

เมื่อชนหรือออกนอกถนน ฉากจะหยุด เมื่อเปลี่ยนแท็บ/ออกจากหน้าต่างหรือการแสดงผลค้างเกิน 300 ms จะพักฉาก ต้องกดขับต่อ

## ไฟล์ที่ใช้

- `pc/app.mjs`: ปุ่ม คีย์บอร์ด รอบอัปเดต และหน้าจอ
- `pc/manual.mjs`: คำสั่งคนขับ การประเมินอันตราย และสถานการณ์
- `pc/core.mjs`: แบบจำลองโลกที่ใช้ร่วมกับต้นแบบเดิม (ส่วน controller อัตโนมัติเดิมไม่ได้ถูกเรียกใช้ในเวอร์ชันนี้)
- `pc/view3d.mjs`: ถนน รถ ล้อ และกล้อง three.js
- `pc/index.html`, `pc/style.css`, `pc/manual.css`: หน้าตาโปรแกรม
- `tests/manual.test.mjs`: ทดสอบการขับ การเบรก ความเสี่ยง และรถด้านหลัง

Export JSON ส่งออกบันทึกเหตุการณ์และสถานการณ์ ไม่ใช่ข้อมูลตำแหน่งทุกเฟรม

การเชื่อม STM32 เป็นขั้นถัดไป: เปลี่ยนแหล่งพวงมาลัยเป็น ADC ของ PA4 และปุ่มเบรกเป็น PB4 รวมถึงย้ายส่วนประเมินไป firmware พร้อมออกแบบข้อความ UART ให้ตรงกัน

## ผลตรวจ

ผ่านการทดสอบอัตโนมัติ 8 กลุ่ม: คันเร่งถูกตัดเมื่อเบรก, ไม่ควบคุมแทนคนขับ, ระยะเบรก, รถด้านหลัง, เงื่อนไขแนะนำซ้าย/ขวา, การเลี้ยว/ชน, จำนวนวัตถุและ ID, TTC/เวลาตอบสนอง

ตรวจหน้าเว็บจริง: ฉาก 3D โหลดสำเร็จ เริ่มขับและปรับคันเร่งแล้วความเร็วเพิ่ม ปุ่มพักทำงาน และเพิ่มรถด้านหน้าแล้วแสดงคำเตือนเบรก

รันการทดสอบโดยใช้ Node.js:

```powershell
node tests/manual.test.mjs
```
